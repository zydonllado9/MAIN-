Skills & plugins videos 2, 3, 5, 8

In repo means the skill is already in volt-3d-website/.claude/skills/. Claude Code picks it up when you open that repo, and you can call it with its /name. To use one in every project, copy its folder to ~/.claude/skills/. Install means it's a plugin: paste the commands into Claude Code.

Skill Creator Anthropic

In repovideo 2

Builds new skills, tests them with evals, and tunes their descriptions so they trigger reliably. Use it to turn any workflow you repeat into a skill.

/skill-creator

Stop Slop Hardik Pandya

In repovideo 2

Strips AI writing tells: stock phrases, "it's not X, it's Y" structures, throat-clearing openers. Use it on any copy you write for the site or socials.

/stop-slop

In repovideo 2

A searchable design database (UI styles, palettes, font pairings, UX rules, chart types) plus scripts that generate a design system for your product. Needs Python 3.

/ui-ux-pro-max

Taste Skill Leonxlnx · tasteskill.dev

In repovideos 5, 8

Anti-slop frontend design: infers a design direction, then ships pages that don't look templated. Five style variants from the same repo are in the repo too: redesign, soft (high-end), minimalist, brutalist, and full-output.

/design-taste-frontend
/redesign-existing-projects

Impeccable Paul Bakaus · impeccable.style

In repovideos 5, 8

Gives you designer vocabulary as commands: audit, critique, polish, typeset, animate, colorize, harden and more. Chain them: /impeccable audit, then polish. The full plugin adds a live in-browser editor and hooks.

/impeccable critique landing page
/plugin marketplace add pbakaus/impeccable

Emil's design engineering Emil Kowalski · animations.dev

In repovideo 8

Emil Kowalski's rules for UI polish and motion: easing, timing (UI animation under 300 ms), and the small details that make an interface feel good. Best used per task, not always on.

/emil-design-eng

Playwright CLI Microsoft

In repovideo 5

Lets Claude open a real browser, click through your site, take screenshots and check its own work. Install the CLI once on your computer.

img2threejs hoainho

In repovideo 5

Rebuilds the object in a reference image as a procedural Three.js model written in code, then compares renders against the image. A good fit for the VOLT can scene. Needs Python 3.10+.

3 things to set up in Claude today video 1 · @walidsadvice

Turn on memory

  1. claude.ai → Settings → Capabilities.
  2. Turn on Search and reference chats.
  3. Turn on Generate memory from chat history.
  4. Optional: Import memory from another AI app.

Connect 1,000+ apps with Composio

  1. Sign up at composio.dev and copy the MCP URL.
  2. Claude → Customize → Connectors → Add custom connector.
  3. Name it Composio and paste the URL.
https://connect.composio.dev/mcp

Learn from Anthropic's free courses

  1. Open anthropic.skilljar.com (13 courses).
  2. Paste the link into Claude with: "extract the best lessons from this".
https://anthropic.skilljar.com/ extract the best lessons from this

Workflows videos 7, 8, 3

Motion-design studio video 7 · @ray_fu

Claude doesn't render video. It writes code that paints every frame; Playwright screenshots each frame in Chrome; ffmpeg stitches the frames into an MP4.

Build a headless render engine loop. Write code that paints every frame, capture it in Chrome, stitch to MP4.
  1. Install Node.js, ffmpeg, and Playwright with Chromium.
  2. Give it real reference assets, or it defaults to centered text on a purple gradient in all caps.
  3. Ban basic CSS (transition: all .3s ease). Make it use closed-form springs.
  4. Lock cuts to the music: e.g. 120 BPM, cut every 2 beats.
  5. Have Claude watch its own frames, hunt dead frames, and re-render until every scene grades 8/10.
ffmpeg -framerate 30 -i frame_%04d.png -c:v libx264 out.mp4

  2. /redesign-existing-projects for a bigger upgrade that keeps the code working.

Prompt codes video 6 · @sebintel
